## 5. التباعد والأنصاف

- شبكة Tailwind الافتراضية (مقياس 4px) — `gap-4 = 16px` إلخ. لا قيم `px` خام خارج المكوّنات الأساسية.
- مقياس الأنصاف: `--radius-xs/sm/md/lg/xl/2xl/3xl = 6/8/10/12/16/20/28px` — كتلة `@theme`
  غير-inline فالمتغيرات متاحة أيضًا في وقت التشغيل للأنماط المضمّنة. عمليًا (r130):
  `rounded-md` (10px) للأزرار والحقول، **`rounded-xl` (16px) للبطاقات والحواريات
  والألواح الداخلية** (dialog.tsx/card.tsx يحملانها فعليًا)، و`rounded-2xl` (20px)
  درجة الهبوط فقط (بطاقات اللاندينغ ولوحات الجوال السفلية)، و`rounded-full` للحبوب والشارات.
- عناصر اللمس في الشريط الجانبي: `min-h-11` (44px — نفس معيار Smart-Menu).
- سلم النص المجاهري: `text-3xs` (10px/1.4) و`text-2xs` (11px/1.45).

## 7. RTL والاتجاه

- الوثيقة كلها `dir="rtl"` مع خط عربي.
- **كل حقل إدخال `<Input>` يحمل `dir="auto"`**: الأرقام/البريد تُعرض LTR تلقائيًا، والعربية RTL، دون كسر أي نموذج.
- `text-left` + `font-mono` تبقى للهواتف/المبالغ داخل حقول dir=auto (تلقائي مع الأرقام).

## 9. الحركة والطبقات

- سلم الحركة: `--t-micro 80ms` → `--t-fast 160ms` → `--t-base 240ms` →
  `--t-slow 380ms` → `--t-slower 520ms` → `--t-cinema 720ms`
  (+ الاسم المستعار `--duration-fast/base/slow = 160/240/380ms`).
- منحنيات: `--ease` (قياسي)، `--ease-out` (استقرار أُسّي)، `--ease-in`،
  `--ease-soft`، `--ease-spring` (التجاوز)، `--ease-spring-soft`.
- الضغط = تصغير وليس غوصًا: `active:scale-[0.97]` مع ارتداد 80ms؛ رفع
  hover بحد أقصى −1px وفقط على مؤشرات hover حقيقية.
- `--motion-direction: 1` / `-1` تحت RTL — اضرب كل انتقال X فيه.
- **أفعال الروبوت (`rb-*`):** تنفّس LED 3.8s، مسح الواقي 1.6s، تدرّج الصوت 1.1s،
  الخلل 2.2s، الموجة 2.4s — كل فعل يحمل مفتاح prefers-reduced-motion الخاص به.
- prefers-reduced-motion: تصفير السلم + الحزام العام (0.01ms !important).
- z-index هرمي مثبّت: dropdown(10) < sticky(20) < nav(30) < modal-backdrop(40) < modal(50) < toast(60) < tooltip(70).

## 10. قائمة رفض أنماط «AI النمطية» (مستلهمة scroll-craft)

ممنوع في أي صفحة جديدة:
1. شبكات بطاقات-ميزات متطابقة تمامًا (3 أعمدة × نفس البطاقة).
2. عدادات زخرفية `01/06` على الأقسام.
3. إشارات تمرير/scroll زخرفية بلا وظيفة.
4. تدرجات بنفسجية-زرقاء نمطية «AI».
