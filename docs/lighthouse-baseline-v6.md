## 1. العيوب البنيوية الحقيقية التي وجدها الفحص (لا تظهر في الدرجات وحدها)

هذه هي الجوهر — أربعة عيوب مؤكدة بالفحص المباشر للـHTML المُسلَّم للزائر، كلها أُصلحت:

### 1.1 — العنوان `<h1>` كان **فارغًا تمامًا** في الإنتاج
```html
<!-- الإنتاج v5 (فحص مباشر): -->
<h1 ...><div data-kinetic="lines"></div>...<div data-kinetic="words"></div>...</h1>
```
KineticText كان يقسّم النص داخل `useEffect` — أي أن نص العنوان **لا يوجد في HTML إطلاقًا** حتى الترطيب. عيب ثلاثي: SEO (h1 فارغ للزواحف)، LCP (أكبر نص لا يُرسم إلا بعد JS)، وa11y (h1 فارغ بلا JS). **بعد v6:** النص كامل في HTML من أول بايت (مُتحقق منه curl على البناء الجديد).

### 1.2 — عمود البطل كله مخفي حتى الترطيب
فحص HTML الإنتاج: **15 عنصرًا** في قسم البطل تحمل `style="opacity:0;transform:translateY(18px)"` (حالات framer-motion الابتدائية تُخبز في HTML) — العنوان والوصف والأزرار وشريط الثقة كلها بيضاء حتى تحميل وتنفيذ JS. على جوال مخنوق = LCP 6.3 ثانية من أول قياس. **بعد v6:** حركات دخول CSS خالصة (تُنفذ عند تطبيق الأنماط، بلا JS) + h1 بلا أي حركة (LCP عند أول رسم).

### 1.3 — `/subscribe` مدرج في sitemap لكنه **يحوّل الزائر لصفحة الدخول**
قياس Lighthouse كشف `final URL = /login?redirect=/subscribe` — رابط sitemap يوجّه لإعادة توجيه = عيب SEO، والصفحة كانت `ssr:false` (الزاحف يرى هيكلًا فارغًا). **بعد v6:** الصفحة عامة (الخطط للجميع — بياناتها من `/api/plans` العام)، والمصادقة تُفرض عند خطوة الدفع فقط (401 → توجيه لطيف لتسجيل الدخول مع العودة)، وSSR مفعّل. القياس: SEO 69 → **100**.

### 1.4 — framer-motion في المسار الحرج + ترطيب كامل الصفحة
- `page.tsx` كان `"use client"` كاملًا → 966KB JS مبدئي تُنفق ترطيبًا (scriptEvaluation 2.4-3.3 ثانية على جوال مخنوق).
- **بعد v6:** الصفحة مكون **خادم** + جزر عميل صغيرة (القائمة، البارالاكس، الموك-أب، شريط الثقة الحي، الشهادات)؛ الأقسام السفلية (ميزات/كيف يعمل/إحصاءات/أسئلة/CTA) تحميل كسول `next/dynamic`؛ framer خرج من مسار الهبوط الحرج كليًا (Hero وHeader وScrollParallax حركة CSS).

### 1.5 — إضافات الأداء الأخرى
- 6 صور `<img>` خام → `next/image` (أبعاد صريحة → صفر CLS، lazy، `priority` لأيقونة شاشات الدخول)
- `robots.ts` (كان مفقودًا — sitemap موجود)
- أرقام الموك-أب الموحدة ar-LY (كانت أرقامًا هندية ١٢٤٧)

### 2.3 — تفسير هندسي صادق للفجوة المتبقية
- **الجهاز المستخدم للقياس مشترك** — خنق CPU 4x فوق معالج مشغول يضخّم TBT؛ التشغيل الواحد يتأرجح ±10 (الدليل في العمود الأخير). الدرجات الخام (§2.1) تثبت أن البنية سليمة.
- **وزن الإطار نفسه:** ~950KB JS مبدئي للهبوط (react-dom + تشغيل Next + الجزر) — لا تسريب كود لوحة (مُتحقق: grep للسلاسل المميزة = 0). التقليص الجذري يتطلب حِمل CSS مقسّمًا لكل مسار وSSR بيانات للوحة — موثّقان كخطوات تالية، خارج نطاق اليوم بقرار واعٍ (مخاطرها أعلى من مكسبها في هذه الجولة).
- bp=96 محليًا = أثر محلي فقط (`/_vercel/speed-insights/script.js` لا يوجد إلا على Vercel — على الإنتاج bp=100 كما في جدول «قبل»).
- SEO للصفحات المصرّح بها (dashboard/login) = `noindex` **بالتصميم** (مناطق مصادقة) — النقطة 66/69 ليست عيبًا.
