## 0) المبدأ الحاكم

جولة v14 أغلقت حرجات كودية. جولة v15 فعلت شيئاً مختلفاً: **اصطادت الحقيقة الإنتاجية** — ميزات مدفوعة كانت تعلن أنها تعمل وهي ميتة صامتة (البوت من أول رسالة! البث! حملات scheduled!)، عدالة البطارية نفسها (ادعاءات لا تفشل شيئاً)، ومراقبة لا تنذر أحداً (قواعد إنذار 404). شعار الجولة: «الأخضر الذي لا يُقاس بصرامة هو أحمر مؤجل».

## 3) عالية الأثر مغلقة (مختارات)

- **حدود الخطة مفروضة فعلاً** (D2-H1): نقطة قراءة مركزية `get_plan_limits` + بوابات max_replies/has_dm/has_broadcast/has_ai — انقلبت خضراء حية بالبطارية (p10)
- **عداد ذرّي** (D12-H3): نمط credit_wallet + فترة date-based — اختبار gather يثبت أن RMW القديم كان يفقد التحديثات
- **ترحيلة 014**: قيود التفرد التسعة (السبعة + uq_reply + uq_user_email_lower) + backfills خصم + server_defaults + reconcile
- **claim النشر المجدول** (D12-H1): `publishing` RETURNING — نبضان لا يزدوجان (اختبار interleave)
- **409 عربية** (D13-F1 نهائياً): عائلة الربط المزدوج/CRM/البريد — بطارية قلبت `SIM_STRICT_409=1`
- **SSRF بفجوة DNS مغلق** (D6-H2): `_resolve_host_ips` + رفض الداخلية بعد الحل — + flow-webhook (D2-H2)
- **401 عالمية** (D4-H3): المغلف المركزي يوجّه /login بلا حلقات — مثبتة حية (p01/p14)
- **انتهاء متناظر** (D10-H1): PAID منتهٍ → UNPAID عند أول استخدام + رسالة تجديد + EXPIRED_TRIAL يواصل الردود
- **فواتير الاشتراك تظهر أخيراً**: (بطارية p10-t11) — /api/payments/history يدمج subscription_payments مع الشحنات (المستخدم كان يدفع ولا يرى الفاتورة — مرساة ضعيفة أخفتها جولتين)
- **الأداء**: X1 (آخر الردود) + B1 (dedup مفهرس + TTL) + B3 (تجميع dashboard + كاش) + B2 (خنق تعليقات)
- **المراقبة**: **قواعد إنذار Sentry الثلاث حية** (25927/25928/25929 — أول إنذارات فعلية في تاريخ المشروع: خطأ api مرتفع + أخطاء web + انقطاع canary) + scrubber PII + إصدار الواجهة SHA حقيقي + v2.2.0
- **a11y حية**: KpiCard شفاف→صلب (axe عبر المعالج) + رابط Graph underline (1.4.1) + توكن placeholder بالمعالج + تركيز عنوان الخطوة عند التقديم
