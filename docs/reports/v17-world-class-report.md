## 0) المبدأ الحاكم

v15 اصطادت «الحقيقة الإنتاجية»، v16 اصطادت «الأمان وصدق القياس». v17 اصطادت **اكتمال التجربة والوظيفة**: أشياء يدّعيها المنتج أو يَعِدها للعملاء كانت إما مستحيلة الاستخدام (قالب يفشل 422 منذ واجهته)، أو ميتة الوصول (ميزة مدفوعة بلا صفحة)، أو غير مكتملة التفاعل (مسودة تنتقل بين العملاء، unread يكذب، جوال يكبّر الحقول). كل بند في هذا التقرير بكود + اختبار أو دليل حي.

## 1) الحصيلة التشخيصية (11 تقريرًا — 2,582 سطر أدلة)
