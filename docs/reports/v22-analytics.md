## 1) F1 (P1) — كل مسارات تقارير PDF كانت 500 في الإنتاج

**ما اختُتبَر (W1-D9):** `GET /api/reports/status` + `POST /api/reports/generate` (شهرية/مشتركين/حملة + type=bogus) → **500×4 حية**؛ السبب: `import weasyprint` على Vercel serverless يرفع **OSError** (مكتبات نظام pango/cairo غائبة) وفحص التوفر كان يلتقط ImportError فقط → الوكيل الكسول يعيد رمي الاستثناء قبل أي منطق تقارير. الواجهة كانت تُبقي زر PDF مفعّلًا (undefined ≠ false) → توست خطأ.

**الإصلاح (c6d10816):**
- الفحص ينجو من **أي** فشل استيراد: `/api/reports/status` → 200 `{available:false, engine:"none", probe_error}` (الواجهة تعطّل الزر برسالتها العربية الصادقة «محرك التقارير غير متاح حالياً على الخادم»)؛ `generate` → **503** نظيف «محرك التقارير غير متاح»؛
- إصلاح مسار fpdf الاحتياطي (fpdf2 يعيد bytearray بينما `.encode('latin-1')` كان عقد fpdf1 str) — المسار المتدهور يعمل فعلًا حيث fpdf2 مثبت.

**النتيجة:** **PASS** — لا 500؛ الحالة غير المتاحة صادقة عبر API+UI (سويت FIX-E).
