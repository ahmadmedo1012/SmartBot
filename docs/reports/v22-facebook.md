## 7) دليل تشغيل المالك (OWNER OPS RUNBOOK) — تفعيل البيانات الحية

> الترتيب مهم: الصلاحيات أولًا، ثم توكن جديد يحملها، ثم إعادة الربط (يفعّل الاشتراك ويكتب حالة صحية خضراء)، ثم ضبط webhook مستوى التطبيق، ثم التحقق.

1. **منح صلاحيات التطبيق** (developers.facebook.com → التطبيق → App settings → Permissions): `pages_manage_metadata` (الاشتراك في الأحداث — **الحرجة**)، `pages_read_engagement` (العدادات)، `pages_read_user_content` (التعليقات)، `pages_messaging`، `pages_manage_posts`، مع إبقاء `pages_show_list`. إذا كان التطبيق في وضع Development: يلزم أن يكون المالك (مشرف الصفحة) عضوًا في التطبيق (admin/developer) ليعمل غير المراجَع، أو قدّم App Review.
2. **توليد توكن صفحة يحمل النطاقات**: من Graph API Explorer — اختر الصلاحيات → توكن مستخدم → Get Page Access Token (أو `GET /me/accounts?fields=access_token` بتوكن مستخدم محدود النطاق). التوكن الحالي وُلّد بلا النطاقات المتقدمة — لا يكفي إعادة الربط به.
3. **إعادة الربط في SmartBot**: `/connect` → PUT /api/facebook/settings بالتوكن الجديد و`subscribe_webhook: true` → يُنفَّذ `POST /{page}/subscribed_apps` تلقائيًا، وأي فشل يظهر الآن بالسبب العربي الحقيقي + حالة BotState دائمة.
4. **webhook مستوى التطبيق** (App Dashboard → Webhooks → object «Page»): Callback URL `https://api.smart-link.ly/webhook`، Verify token = قيمة `FB_WEBHOOK_VERIFY_TOKEN` (موجودة في بيئة Vercel)، حقول الاشتراك: `messages`, `feed`. يُستحسن إضافة `FACEBOOK_APP_SECRET` إلى بيئة Vercel (حاليًا يحملها SystemConfig من DB فقط).
5. **قائمة التحقق بعد التنفيذ**:
   - `GET /{page}/subscribed_apps` غير فارغ (أو `/api/facebook/test`)؛
   - لافتة «متصل لكن الويبهوك غير مفعل» تختفي من اللوحة (الحالة الخضراء تُكتب من النبضة التالية ≤5 د)؛
   - أرسل رسالة تجريبية للصفحة → تظهر في /dashboard/messages خلال ثوانٍ + صف subscriber يُنشأ + الرد الآلي يعمل؛
   - `/api/posts` بعد المزامنة → عدادات غير صفرية.
6. **ملاحظات صيانة**: r22 يبقي j22 (نصف ربط قديم بلا page_id — خامل) مرشحًا للتنظيف عبر مسار فصل الربط في التطبيق (لا SQL مباشر)؛ الفشل برمز 403 #200 في حالة أي مستأجر = اسم الصلاحية الناقصة مكتوب في `webhook_state.missing` مباشرة.
