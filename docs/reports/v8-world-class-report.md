## المسار A — أمن وصحة الباكند (12/12)

- **A1** (الأخطر): `GET /api/config` كان يقرأ *كل* صفوف SystemConfig غير السرية — ومفاتيح OpenAI/Gemini كانت تُحفظ `is_secret=False` فتسرب للعامة. الحل المزدوج: قائمة سماح صريحة (`_PUBLIC_CONFIG_KEYS` — 11 مفتاح دفع/دعم فقط) + إضافة المفاتيح لـ`_SECRET_KEYS`. اختبار انحدار يزرع الحالة القديمة المسمومة ويثبت عدم التسريب.
- **A2**: SSE `/api/events` كان مشتركًا عالميًا (`tenant_id=None`) يبثّ أسماء عملاء المستأجرين الآخرين وردود AI كاملة. الآن يشترك بـ tenant المستخدم + `agent_message` يُبث scoped.
- **A3-A12**: عدادات لكل tenant، رفع Vercel-safe، وسم فريد لكل tenant، مقارنة ثابتة الزمن، ترتيب الوسائط (403/429 تحمل ترويسات الأمن الآن)، غلاف العقد، تعريب 10 رسائل، حدود pagination، تخزين fan-count (5 دقائق — كان نداء Graph حيًا يعطل اللوحة)، دفعة upsert + قفزة 30s (كانت 50 SELECT تسلسلية للنداء الواحد).

## المسارات B/C/D/E — 150+ تعديلًا عبر ~70 ملفًا

**الحركة**: الرقصة الميتة أُحييت (Variants) · MotionConfig للمطابقة مع `prefers-reduced-motion` · توست واحد عبر 105 نداء (brandedToast) · حوار 250ms بمنحنى التوكن · `transition-[colors,transform]` غير الصالح أصلح (4 مواضع — الألوان كانت تقفز فوريًا) · `border-r-orange` الوهمي → `border-s-primary` (جانب منطقي).

**الإتاحة**: الساحر/الورقة حوارات كاملة النمط (نسخة Header النموذجية) · بطاقات إشعارات بلوحة مفاتيح · رابط التخطي يستهدف المحتوى فعلًا (الشريط الجانبي خارج الهدف) · 18 حقل نموذج · h1 لكل صفحة · روابط خارجية «يفتح في تبويب جديد» · مسار تنقل «مسار التنقل» + `aria-current` · autocomplete (tel/name/email) · مخططات بملخصات sr-only · مستويات السجل نصًا لا لونًا فقط · مناطق حية للنتائج اللاتزامنية · خطأ التحقق مرتبط بـ aria-describedby.

**نظام التصميم**: سلم نصف قطر **رتيب** 8/12/16/20/28/36/44 (كان `rounded-2xl` أصغر من `rounded-xl`!) · البطاقات/الحوارات توحّدت على 28px · 101 صنف لون خام → التوكنات الدلالية (`bg-success-soft text-success`…) — تتبدل مع الثيم وتحفظ AA · `ease-smooth` التوكن بدل 5 منحنيات حرفية · badge حبّي · 0 توستات بيضاء في الوضع الداكن.

**النسخ العربية**: 6 أخطاء P0 (منها بقايا «منيو» من Smart-Menu) · معجم موحّد لـ5 مفاهيم كانت تتوزع 13 تسمية · `جارٍ` موحّدة · أرقام غربية · `timeAgo` واحدة (كانت 3 صيغ متنافرة: «منذ 5 د» / «قبل 5 دقيقة» / «منذ 5 دقائق») بلا مثنى/جمع — الآن بالمثنى والجمع الصحيحين عبر محرّك الجمع الموجود أصلاً · عزل bidi لعناوين URL · أمثلة أحداث SmartBot بدل `restaurant_created`.

**التفويض المتوازي**: ثلاثة وكلاء نفّذوا بالتوازي مسح الألوان (89 موضعًا script + 0 GREP خام)، EmptyState/Skeleton (26 حالة فارغة + 25 عنصر هيكل عبر 21 ملفًا — كانت 5 لغات فارغة مختلفة)، وتفاصيل a11y الـ12 — مع إعادة قراءة الملفات عند التقاطع، وtsc نظيفًا بعد كل دفعة.
