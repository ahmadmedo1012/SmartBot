## 1. ما اكتشفه الفحص الممل (ولماذا كانت الشكاوى حقيقية)

فُحص مشروع Smart-Menu بالاستنساخ الكامل (`github.com/ahmadmedo1012/Smart-Menu` — خاص) وجنبًا إلى جنب مع SmartBot بواسطة وكيلين متوازيين + فحص مباشر. النتائج الجذرية:

| الشكوى | الجذر الحقيقي (بالدليل) | الحالة |
|---|---|---|
| «الخطوط مختلفة» | `fonts.css` في SmartBot **لم يكن يُعرّف خط Cairo إطلاقًا** — كل النص العربي كان يُرسم بـ Noto Sans Arabic | ✅ أُصلح — Cairo حي ومتحقق |
| «الشعار لا يظهر» | لا favicon.ico ولا icon-192/512 ولا apple-touch-icon؛ manifest يعلن أحجامًا خاطئة | ✅ حزمة كاملة مولدة ومتحققة |
| «كلها أصفار بعد الربط» | كل نقاط البيانات كانت تستخدم client البيئة العامة وليس توكن المستأجر + الويبهوك لا يعالج الرسائل أصلًا + **سر التطبيق غير مضبوط** فكان يرفض كل الأحداث 401 | ✅ أُصلح بالكامل (انظر §2) |
| «إشعارات التليجرام لا تصل» | التوكن والمدراء من env فقط (غير مضبوط) + POST config دالة وهمية + جدول Approvers غير مستخدم | ✅ أُصلح — DB-first |
| «تداخلات وتشوهات» | قائمة رسائل w-96 ثابتة تبتلع الجوال، زر عين خارج حاويته، grain فوق المحتوى z-40، بطاقات rounded-sm قديمة | ✅ أُصلحت |
| «لوحة التحكم تحتاج تحسينًا» | شارة «متصل» مكتوبة يدويًا، أصفار بلا تفسير، أزرار ميتة، صفحات عرض فقط | ✅ أُصلحت (انظر §3) |

## 2. الإصلاحات الوظيفية الحرجة (فيسبوك من طرف لطرف)

1. **تغطية المستأجر الشاملة**: `/api/messages` و`/api/posts` و`/api/ads/*` و`/api/publish` والردود — كلها تستخدم توكن المستأجر المتصل (كانت تستخدم client env العام → فراغ دائم).
2. **استقبال رسائل الماسنجر**: `POST /webhook` يعالج الآن `entry[].messaging[]` — تخزين في جدولي `conversations`/`messages` (ترحيل 008، dedup ضد إعادة الإرسال، حل معرف المحادثة الحقيقي من Graph API).
3. **ردود تلقائية للرسائل**: `BotEngine.process_single_message` — نفس محرك القواعد/النية/التبريد المستخدم للتعليقات، يرد عبر DM مباشرة، مع محاسبة عدّاد الاستخدام وإشعار WS.
4. **لوحة البيانات الصادقة**: علم `connection.connected` حقيقي + إحصاءات الرسائل المخزنة + اسم الصفحة + fan_count من client المستأجر.
5. **سر التطبيق من قاعدة البيانات** (الاكتشاف الأخير بالتحقق الحي): كانت بيئة الإنتاج بلا FACEBOOK_APP_SECRET → الويبهوك رفض كل حدث منذ الإطلاق. الآن يُحل env → SystemConfig، ويدخله المالك من `/admin/settings`.
6. **صفحة الربط الصادقة**: قائمة صحة ويبهوك (العنوان القابل للنسخ + حالة السر + حالة اشتراك feed/messages) بدل «كل شيء يعمل» الكاذبة.
7. **تليجرام**: توكن + معرف الدردشة من SystemConfig (env fallback)، المدراء = env ∪ جدول Approvers، `POST /api/telegram/config` يحفظ فعلًا، `POST /api/telegram/test` يرسل رسالة حقيقية، الموافقة/الرفض من تليجرام يتحقق من مدراء القاعدة أيضًا.

## 3. مطابقة Smart-Menu البصرية (الحرفية)

- **fonts.css** نسخة مطابقة بايت-ببايت (Cairo 400-800 بثلاث مجموعات فرعية + Readex + Noto) + preloads لـ cairo-arabic/readex-pro + إزالة next/font/google.
- **حزم التوكنز**: --muted-foreground 0.62 (AA)، --c-flame/ash/night/basil، --whatsapp/-deep، --glass-border-strong، grain 0.022/z-1، زجاج 16/20px، card-premium radius-lg + color-mix، تايبوغرافي 1.35/400/1.65، حارس tracking العربي.
- **المكونات المنقولة حرفيًا**: Card (نظام --card-spacing + elevations + spotlight + CardAction)، KpiCard (عدّاد متحرك + stagger + روابط ممتدة)، ChartCard، MiniSparkline، Textarea، GridPattern، EmptyState بحلقة الأيقونة، Badge tinted، Input h-12 بحالات، زنبركات Smart-Menu (120/14، 200/20، 300/24).
- **Toaster** top-center بأسلوب Smart-Menu، **manifest** بأيقونات حقيقية + maskable، **OG** بالبطاقة 1200×630.
- **صفحات**: الداشبورد الرئيسية أعيد بناؤها على KpiCard، الرسائل master-detail متجاوبة، البث الجماعي تدفق إنشاء+إرسال كامل، الفواتير زر اشتراك، الفريق حالات خطأ + أدوار مترجمة، خرائط ترجمة الحالات لكل الصفحات، locale موحد ar-LY، [...slug] بملخص مقروء بدل JSON، إعدادات المستخدم تغيير كلمة مرور فعلي.

## 4. التحقق الحي (متصفح حقيقي على الإنتاج)

- Cairo محمّل ومُطبق على العناوين والنصوص (`document.fonts.check('600 1em "Cairo"')` = true)
- الشعار naturalWidth>0 في الرئيسية والدخول؛ favicon.ico/icon-192/icon-512/apple-touch-icon كلها 200
- الأيقونات في HTML head كاملة + manifest بالأحجام الصحيحة
- القيم: --orange ≈ #bc4700، muted 0.62، لا تجاوز أفقي في كل الصفحات المفحوصة
- زر العين داخل حاويته (relative) في الدخول
- إعدادات الأدمن: البطاقات الأربع حية (دفع/دعم/تليجرام/ويبهوك) + زر الرسالة التجريبية
- الرسائل على جوال 390px: القائمة 390px كاملة العرض بلا overflow
- صفر أخطاء كونسول في الصفحات المفحوصة
- الويبهوك يرفض غير الموقّع (401) والـ check يعرض العنوان المستقر api.smart-link.ly

## 5. ما ينتظر المالك (خطوات الإطلاق الأخيرة — بيانات سرية لا يعرفها إلا المالك)

1. **سر تطبيق فيسبوك**: من developers.facebook.com ← تطبيقك ← Settings ← Basic ← App Secret → الصقه في `/admin/settings` (بطاقة «توقيع ويبهوك فيسبوك»). *بدونه لن تُقبل أي أحداث.*
2. **ربط الصفحة**: من `/connect` بمعرف الصفحة + Page Access Token (من أدوات Graph API أو Business Manager). عند الحفظ يُجلب اسم الصفحة تلقائيًا ويُشترك بحقلي feed+messages.
3. **تسجيل الويبهوك** (إن لم يكن مسجلًا): developers.facebook.com ← Webhooks ← Page: Callback = `https://api.smart-link.ly/webhook` (زر نسخ جاهز في صفحة الربط) + Verify Token نفسه المضبوط + حقلا feed وmessages.
4. **تليجرام**: توكن البوت من @BotFather في `/admin/settings` + أرسل /start للبوت + جرّب زر «إرسال رسالة تجريبية». المدراء الإضافيون من لوحة الإدارة.
5. **بيانات الدعم والدفع**: بطاقتا «بيانات الدفع» و«معلومات الدعم» في نفس الصفحة.
6. **تغيير كلمة المرور** من إعدادات المستخدم (الجديدة الآن) وإبطال كل التوكنات (GitHub PAT + أي توكنات جلسية).
