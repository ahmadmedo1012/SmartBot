# دليل المستخدم — SmartBot بالعربية

> لكل صاحب صفحة فيسبوك يريد بوتاً يرد على عملائه نيابة عنه.

## أولاً: إنشاء حسابك وربط صفحتك

1. **التسجيل**: من زر "ابدأ الآن" في الصفحة الرئيسية → اسم مستخدم + بريد + كلمة مرور (6 أحرف على الأقل).
2. **ربط صفحة فيسبوك**: من لوحة التحكم → **الصفحات**:
   - `Page ID`: رقم صفحتك (أو `m.me/اسم-صفحتك` ← الرقم في الرابط).
   - `Page Access Token`: من أداة [Graph API Explorer](https://developers.facebook.com/tools/explorer/) باختيار صفحتك والصلاحيات: `pages_manage_engage_posts` و`pages_read_engagement` و`pages_messaging`.
   - الرمز **يُشفَّر** في قاعدة البيانات ولا يُعرض مجدداً.
3. **اختبار الاتصال** قبل الحفظ للتأكد صلاحية الرمز.

> جرب بلا تسجيل من صفحة **التجربة** (`/demo`) ببيانات وهمية.

## ثانياً: أول قاعدة رد تلقائي

من **الردود التلقائية** → "قاعدة جديدة":

| الحقل | مثال | ملاحظة |
|-------|------|--------|
| اسم القاعدة | `سعر التوصيل` | لتمييزها في القائمة |
| الكلمات المفتاحية | `توصيل، شحن، delivery` | تطابق شامل جزئي، غير حساس للهمزات والنقاط |
| نص الرد | `التوصيل داخل طرابلس 10 د.ل 🚚` | يُنشر كرد على التعليق |
| الرد الخاص (اختياري) | `أرسل موقعك هنا…` | DM تلقائي بعد الرد |

اضبط **الأولوية** (رقم أقل = تُطبَّق أولاً عند تعدد المطابقات) و**التمكين**.

## ثالثاً: كيف يعمل البوت؟

- **وضع الاستماع الفوري (webhook)**: يرد خلال ثوانٍ من نشر التعليق — يتطلب ضبط الـ webhook (راجع [النشر](deployment.md)).
- **وضع الدورة الخلفية**: كل 10 ثوانٍ (قابل للضبط من الإعدادات).
- **الحمايات المدمجة**: لا يرد مرتين على نفس التعليق (dedup)، فترة تهدئة 60 ثانية لكل مستخدم، بحد أقصى 5 ردود لكل منشور في الدقيقة.
- **إنفاذ الاشتراك**: انتهاء فترة التجربة → يبقى الرد الأساسي ويوقف الميزات المدفوعة (AI، البث، الجدولة).

## رابعاً: الاشتراك والدفع

من **الاشتراك** (`/subscribe`) اختر الباقة:

| الباقة | السعر شهرياً | الأبرز |
|--------|--------------|--------|
| مجاني | 0 | 100 رد، صفحة واحدة |
| أساسي | 19 د.ل | 2,000 رد + ردود AI + DM |
| مميز | 29 د.ل | 10,000 رد + بث + جدولة + تقارير |
| احترافي | 129 د.ل | 50,000 رد + حملات تسلسلية |
| مؤسسي | 299 د.ل | بلا حدود + دعم 24/7 |

**طرق الدفع** (كلها بالدينار الليبي):
- **ليبيانا / مدار**: للمبالغ حتى 99 د.ل — كود USSD جاهز للنسخ من نافذة الدفع.
- **تحويل بنكي**: إجباري فوق 99 د.ل — تُعرض بيانات الحساب، ترفق صورة الإيصال، وتنتظر موافقة الإدارة (تصل عبر تيليجرام فوراً).

بعد الإرسال: صفحة الانتظار تستقصي الحالة كل 5 ثوانٍ (تتوقف تلقائياً في الخلفية) — عند الموافقة يظهر إشعار **الدفع** في جرس الإشعارات ويتفعّل الاشتراك فوراً.

## خامساً: جولة في لوحة التحكم

| الصفحة | ماذا تفعل فيها |
|--------|----------------|
| **لوحة البيانات** | ردود اليوم/الإجمالي، أداء القواعد، الرسم البياني الحي |
| **الرسائل** | صندوق Messenger مدمج مع ردود جماعية |
| **التعليقات** | آخر التعليقات وما ردّ عليها البوت |
| **التحليلات** | نمو المتابعين، أوقات الذروة، أعلى القواعد |
| **البث الجماعي** | رسالة لكل مشتركي صفحتك بضغطة |
| **التسويق** | حملات موجهة: الكل/النشطون/المتفاعلون/الجدد + إحصاءات وصول |
| **التقارير** | ملخصات أداء دورية |
| **الإشعارات** | تغذية حية (دفع/دعم/تسويق/نظام) + إعدادات التنبيه |
| **الدعم** | تذاكر بأولويات (منخفضة→عاجلة) مع محادثة ردود مع الفريق |
| **الفواتير** | رصيدك وسجل المدفوعات |
| **الإعدادات** | فاصل البوت، 2FA، الثيم، كلمة المرور |

## سادساً: الدعم

- **تذكرة**: صفحة الدعم → "أرسل طلباً" مع تحديد الأولوية → رد الفريق يظهر في نفس الصفحة + إشعار.
- **واتساب/بريد**: تظهر في بطاقة "تواصل معنا" (قابلة للضبط عبر `SUPPORT_*`).

## نصائح سريعة

1. ابدأ بـ 5–10 قواعد تغطي الأسئلة المتكررة فعلاً (الأسعار، التوصيل، أوقات العمل).
2. فعّل الرد الخاص لتحويل التعليقات إلى محادثات Messenger.
3. راقب صفحة **التحليلات** أسبوعياً — القاعدة الأعلى مطابقة هي التي يريدها جمهورك.
4. الباقات فوق 99 د.ل تتطلب بنكياً — جهّز حساب الشركة مسبقاً لدى الإدارة.
